# Generic portraits

`generic-portraits.png` is an original image created with the built-in image generation tool for this game. The atlas has four columns and four rows. Cells 0–7 depict fictional staff; cells 8–15 depict fictional young adult prospects. The UI uses CSS background positions, so the original image remains intact. Staff portraits follow the candidate order in `src/game/staff.ts`; academy faces have saved assignments, vary within the current academy roster, and are preserved on promotion. Existing saves receive stable portrait assignments when first loaded.
